# ✒️ دليل الخطاط العربي | Arabic Calligraphy Toolkit

**مشروع برمجي مفتوح المصدر يُعنى بتقديم أدوات مساعدة للخطاطين والرسامين العرب باستخدام لغة بايثون (Python).**

An open-source Python application designed to provide practical tools and reference data for Arabic calligraphers and artists.

---

## 🌟 عن المشروع (About)

نظراً لندرة الأدوات والمكتبات البرمجية الموجهة لمجال الخط العربي الأصيل، يهدف هذا المشروع إلى بناء دليل وأداة تفاعلية تساعد الخطاط في:
* معرفة مقاسات وقصبات الأقلام المعتمدة لكل خط عربي (ثلث، نسخ، رقعة، ديواني، إلخ).
* إضافة خطوط ومقاسات جديدة وإدارتها برمجياً.
* (مستقبلاً) حساب النسب الفاضلة والقياس بالنقط وتصدير البيانات.

---

## 🚀 الميزات الحالية (Current Features)

- [x] **البحث السريع:** الاستعلام عن حجم القلم المناسب (بالمليمتر) لأي خط عربي مسجل.
- [x] **الإضافة والمتابعة:** إمكانية إضافة أنواع خطوط جديدة وأحجام أقلامها ديناميكياً.
- [x] **واجهة تفاعلية بسيطة:** قائمة نصية تفاعلية تمكن المستخدم من اختيار الخدمة بسهولة.

---
