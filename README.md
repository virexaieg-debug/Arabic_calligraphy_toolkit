# ✒️ دليل الخطاط العربي | Arabic Calligraphy Toolkit

**مشروع برمجي مفتوح المصدر يُعنى بتقديم أدوات حاسوبية ومعايير هندسية للخطاطين والرسامين العرب باستخدام لغة بايثون (Python).**

An open-source Python CLI application designed to manage traditional Arabic calligraphy styles, pen measurements, and traditional geometric rules using clean architecture principles.

---

## 🌟 عن المشروع (About)

يقدم هذا المشروع أداة تفاعلية متكاملة تساعد الخطاط والعاطف بالخط العربي في:
* معرفة وتحديد المقاييس الشريفة للخطوط (مقاس القلم بالملم، عدد نقط الألف، ارتفاع السطر، والمسافة القياسية بين السطور).
* إدارة قاعدة بيانات الخطوط ديناميكياً مع حفظها واستعادتها تلقائياً.
* الاعتماد على نظام برجمي كائني (OOP) محمي ضد أخطاء الإدخال.

---

## 🚀 الميزات الحالية (Current Features)

[x] البرمجة الكائنية (OOP): تمثيل الخطوط والأدلة بواسطة كلاسات مستقلة لتقديم تفاصيل ومقاييس كل عنصر بمرونة.
[x] حاسبة النسب الهندسية:
حساب ارتفاع السطر (طول الألف بالملم = مقاس القلم × عدد نقط الألف).
حساب المسافة القياسية بين سطور الأساس (2 \times \text{طول الألف}).
[x] دليل الأحبار التجاري (Ink Guide): قاعدة بيانات شاملة لأشهر الأحبار المستخدمة في الخط العربي (مثل سومي، باركر، بيليكان، شمنكه) مع تفاصيل الألوان، الأحجام، وبلد الصنع.
[x] دليل أنواع الورق (Paper Guide): مرجع تفصيلي لأفضل أنواع الورق (كوشيه، مقهر طبيعي وصناعي، كانسون، شوان، وغيرها) مع مقاساتها وخاماتها والخطوط الملائمة لها.
[x] واجهة مستخدم رسومية (GUI): دعم واجهة تفاعلية باستخدام مكتبة Tkinter لتسهيل الاستعلام والبحث وإضافة الخطوط.
[x] استدامة البيانات (JSON Persistence): حفظ الخطوط المضافة تلقائياً في ملف calligraphy_data.json واسترجاعها عند كل تشغيل.
[x] هيكلة موحدة ومنظمة (Modular Architecture): تقسيم الكود إلى الوحدات التالية:
models.py: الكائنات الأساسية للخطوط.
storage.py: إدارة القراءة والحفظ في ملف JSON.
ink.py: دليل ومحرك بحث الأحبار التجاري.
paper.py: دليل ومحرك بحث الورق ومقاساته.
gui.py: واجهة المستخدم الرسومية (Tkinter).
main.py: التشغيل عبر الواجهة النصية (CLI).
